Giorni di chiusura

Clicca un giorno feriale per chiuderlo (diventa rosso). Le festività ticinesi sono già bloccate in automatico. Al termine, scarica config.json e caricalo su GitHub.

Chiusura aziendale Festività (automatica) Disponibile
Dal al
  1. Clicca Scarica config.json.
  2. Vai al tuo repository GitHub → apri (o crea) il file config.json nella stessa cartella di index.html.
  3. Sostituisci il contenuto con il nuovo file (o carica il file con Add file → Upload files) e fai Commit.
  4. Entro un minuto il calendario del sito mostrerà i giorni chiusi.
